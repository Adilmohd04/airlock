Verify a Staged Agent Authority receipt

Drop an airlock-attestation-*.json file below (or a JSON array of several, to check a chain). This page checks the Ed25519 signature entirely on your device — no network, no dependency on Airlock. If any field of a receipt was altered, verification fails.

Format saa/0.1 · This verifier is self-contained; view source to audit it. Signature algorithm: Ed25519 (WebCrypto).
